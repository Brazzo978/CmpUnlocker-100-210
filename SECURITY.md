# Security policy

Do not open a public issue containing:

- privileged GPU or firmware write techniques;
- signed-firmware validation bypasses;
- payload construction details;
- executable unlock code;
- driver-hook offsets or reproducible exploitation steps.

Use GitHub's private vulnerability reporting feature for this repository. If
private reporting is not available, contact the repository owner through a
private channel before sharing the technical material.

Ordinary corrections to published measurements, documentation and read-only
tools may be reported through normal issues.
