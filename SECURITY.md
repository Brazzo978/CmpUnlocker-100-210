# Security policy

The reviewed Tensor and PCIe Gen2 implementation in this repository is public.
Public issues may discuss its documented behavior, installation and failures,
but must not contain:

- credentials, access tokens or private infrastructure details;
- NVIDIA firmware, VBIOS/ROM images or proprietary driver binaries;
- new, unpublished privileged-write techniques or bypass chains;
- experimental Gen3 hooks, private-symbol offsets or raw reverse-engineering
  dumps outside the reviewed public scope.

Use GitHub's private vulnerability reporting feature for this repository. If
private reporting is not available, contact the repository owner through a
private channel before sharing the technical material.

Ordinary bug reports, compatibility observations and corrections to published
code, tutorials or measurements may be reported through normal issues. Remove
hostnames, addresses, usernames and unrelated logs before attaching output.
